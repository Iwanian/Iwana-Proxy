# ✨ Features

- 🚀 Modern and simple user interface
- 🌍 Proxy collection and checking
- ⚡ Categorization of high-speed proxies
- 🧪 Proxy testing and analysis
- 📡 Latency / Ping testing
- 📊 Smart sorting
- 🌐 Filter by region
- 🔄 Automatic updates
- 💻 Support for Windows, Linux, macOS, and Android
- ❤️ Completely open-source and free
